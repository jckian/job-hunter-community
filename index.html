你的 preference.json

可直接匯入既有的偏好檔，或建立一份空白格式。連結本機檔案後，每次儲存偏好都會更新同一個檔案。

本機檔案由此頁面儲存時更新；在其他編輯器改檔後，請用「匯入偏好檔」重新載入。此功能不會寫入 GitHub。

      每個人有自己的工作台

      網站程式可以公開分享；你輸入的內容只保存在目前的瀏覽器，不會傳到 GitHub 或其他人的電腦。

      使用同一台電腦、同一個瀏覽器設定檔的人會共用這份紀錄。請用各自的瀏覽器設定檔。清除網站資料或結束無痕模式可能會刪除紀錄，記得定期備份。

      怎麼開始？

      1. 到「Preference」填寫自己的條件，按下儲存。
      2. 從「職缺」加入工作，在「待投」安排投遞，再到「紀錄」更新進度。
      3. 隨時更新面試進度、追蹤日期與筆記。
      4. 需要持續更新偏好檔時，連結 preference.json；工作紀錄請另外下載完整備份。

      這是可直接放上 GitHub Pages 的獨立版本。提供依 Preference 掃描公開職缺、投遞紀錄與本機備份。掃描在網頁開啟時執行，不需金鑰；不含 AI 履歷生成或外部通知服務。

      偏好檔直接覆寫需要支援 File System Access API 的瀏覽器（例如桌面 Chrome／Edge），以及使用者授權。不支援時仍可下載、匯入使用。
